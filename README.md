# Blog Personal - Guillermo Velásquez

Blog personal desarrollado con [Astro](https://astro.build/) y alojado en [Cloudflare Workers / Assets](https://developers.cloudflare.com/workers/).

## 📦 Comandos Disponibles

- `npm run dev`: Inicia el servidor de desarrollo local.
- `npm run build`: Compila el sitio estático en la carpeta `dist/`.
- `npm run preview`: Previsualiza la versión compilada de producción en local.
- `npm run deploy`: Compila y despliega los últimos cambios a Cloudflare.
